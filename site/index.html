What compounds

Three multipliers

Exponential is not a bigger number. It is a rate that keeps rising, because the thing limiting it keeps getting relieved.

Multiplier 01

It grows from
your work

Not all possible work — yours: the things you work on, and the way you work on them, read from your own sessions and decisions.

  • Sessions are captured — friction, backtracks and calls you made become lessons.
  • Lessons land as local rules, in a PR you review.
  • The portable ones promote to the canon — and reach every repo you run.

Nothing to author up front. The corpus is a by-product of working.

Multiplier 02 · the one that lifts the ceiling

Prose becomes
checks

A rule the agent might apply is a hope, and it costs context every session to hope it. So prose is promoted into generated checks — lint for how you work. They run when the agent tries to stop; the finding is the instruction.

  1. prose every session the agent may apply it
  2. skill on demand the agent may apply it
  3. check no context it blocks

Every promotion buys certainty and hands back the budget that bought it. That is the exponent.

Multiplier 03

It turns
without you

A loop you have to remember to run is not a loop. Growth and upkeep are scheduled work the repo executes on itself, each with a verifiable outcome.

  • Upkeep on the repo’s schedule — tidy sweeps, wiki growth, prose→check conversion.
  • Every repo re-vendors the canon nightly — no repo falls behind.
  • Every automated change is a PR, gated by your own CI.

The unit that travels

The pack
carries it

Knowledge compounds only if it travels whole. A pack ships a practice with everything it needs to survive — and to be found.

  • Prose — every session, automatically.
  • Checks — the generated lint that enforces it.
  • Skills and tasks — procedure on demand, upkeep on schedule.
  • A manifest — discoverable in the catalog, adopted by interview, visible per repo.

FAQ

Fair questions

Is the chart real data?

No — it is schematic, and asserts no magnitudes. The shapes are the claim: a prose-only corpus saturates against the context budget, and promoting prose into checks keeps freeing it.

What gets added to my repo?

A vendored canon, a declaration, hooks, a scheduler workflow and a CI step — one PR.

Do I have to write the rules myself?

No. Most arrive as lessons mined from your own sessions; you review the PRs that land them.

Will it fight my CLAUDE.md?

No. It adds the layer that file can’t carry, and keeps it lean.

What happens when a check fails?

It holds the session open and states the fix. Repo-facing checks run again on every PR.

Which agents does it support?

Claude Code today. Other agents keep reading your CLAUDE.md.

How do I leave?

Delete .claudinite/, its hook entries, the scheduler workflow and the CI step.
